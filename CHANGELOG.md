# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
а версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [1.1.17] - 2026-11-16

### Added

- При ошибке начального Telegram-входа пользователь может повторить попытку, не открывая защищённые экраны до успешной авторизации.
- Созданы воспроизводимые проверки клиентских сценариев через Playwright и серверных контрактов Edge Functions через Deno; они включены в CI.

### Changed

- Сценарии генерации и чтения текста, словаря и повторения, профиля и доступа разделены на небольшие серверные и клиентские модули без смены основного пользовательского пути.
- Упорядочены навигация, материалы, админские инструменты и конфигурация Telegram-бота; их контракты проверяются тестами.
- Обновлены README и документация для обновления работающего production.

### Fixed

- Отправка отчёта об ошибке ограничена атомарной серверной операцией: не больше пяти отчётов пользователя за скользящий час даже при одновременных запросах.
- Окно отчёта об ошибке получает фокус при открытии, удерживает его внутри, закрывается клавишей Escape и возвращает фокус к кнопке открытия; поле описания имеет видимую подпись.


### Security

- Сервер принимает только разрешённые поля диагностики, очищает известные форматы секретов и не пишет содержимое отчётов и сырые ошибки БД в логи.
- Новая RPC отправки отчёта доступна только service_role; проверка Telegram initData, роли и закрытый доступ к пользовательским таблицам сохраняются.

## [1.0.0] - 2026-09-25

### Added

- Добавлены onboarding и справка production-бота с кнопкой открытия Mini App.
- Главная выбирает приветствие по состоянию текущей сессии.
- Добавлено подтверждаемое удаление ещё не подготовленного слова из активного текста.
- Описан безопасный процесс обработки пользовательских отчётов об ошибках.

### Changed

- Серия чтения сохраняется до пропущенного учебного дня.
- Диагностика support report дополнительно очищается от личных данных.

### Fixed

- Ошибки production backup до начала выгрузки отражаются в состоянии backup.

### Security

- Удаление pending-слова и сохранение AI-карточки выполняются через server-only RPC под общим пользовательским lock, поэтому удаление, сохранение и объединение канонического дубля не оставляют промежуточных состояний.
- Telegram webhook проверяет отдельный секрет и не записывает содержимое update или идентификаторы пользователя в логи.

## [0.1.1] - 2026-07-24

### Added

- Добавлено сохранение позиции чтения между устройствами и управление возвратом к началу текста.
- Добавлены изолированный Telegram dev-запуск, автоматическая пересборка frontend и отдельный каталог `dist-telegram`.
- Добавлены пользовательские release notes, build metadata и автоматическая проверка согласованности релизных артефактов.

### Changed

- Учебный день начинается в `05:00` по московскому времени, а незавершенный активный текст переносится между учебными днями.
- Уточнены состояния дневного прогресса, счетчик прочитанных текстов и представление завершенного повторения слов.
- Размер основного текста для чтения увеличен до `19px`.

### Fixed

- Восстановление активного текста сохраняется после неудачной генерации нового материала.
- Исправлены состояния повторения новых слов и ошибки локального Telegram-запуска.

### Security

- Release metadata ограничена безопасными значениями версии, окружения и Git commit SHA и не включает server secrets.
