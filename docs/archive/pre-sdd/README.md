# Архив до внедрения SDD

`agents/` содержит прежний процесс, три старых скилла и связанные материалы. Они сохранены для понимания устройства приложения при будущем рефакторинге, но не являются действующими инструкциями.

Текущие правила: [AGENTS.md](../../../AGENTS.md), [GIT_POLICY.md](../../../GIT_POLICY.md), [конституция](../../../.specify/memory/constitution.md) и скиллы в `.agents/skills/`, правила кода в `.agents/rules/`. Предметная дизайн-система и инструкция локального Telegram-запуска находятся в `docs/`; руководство ручного тестирования в `.agents/references/`.
