## Наблюдаем

- [[Название карточки]] — каких данных или сценария не хватает.

Правила обновления:

- Не дублировать вопросы, уже присутствующие в этом дневном плане.
- Не переносить вопрос в следующий день, если на него уже дано решение.
- После обработки ответа заменить вопрос статусом карточки или ссылкой на пачку.
- Не изменять и не очищать текст, введенный владельцем после `<mark>решение:</mark>`, пока решение не перенесено в карточку.
- Не создавать TickTick-задачу без явного указания владельца.
- Не ставить `[x]` за владельца.
