# Мои материалы и история чтения

## 1) Область документа
Документ фиксирует текущую модель раздела `Мои материалы`: как пользователь открывает
историю прочитанных текстов, где хранится snapshot завершенного текста и как frontend
получает данные.

## 2) Product rules
- Раздел `Мои материалы` открывается из нижней навигации и с главной карточки.
- В разделе есть табы `Словарь` и `Тексты`; по умолчанию открывается `Словарь`.
- Пункт `Материалы` в нижней навигации открывает раздел `Мои материалы`; когда пользователь находится на этом экране, активным пунктом нижней навигации становится `Материалы`.
- Плитка `Тексты` на главной открывает раздел сразу на табе текстов.
- Плитка `Словарь` на главной открывает раздел сразу на табе словаря.
- Плитка `Словарь` на главной показывает краткий статус словаря по данным `get-vocabulary-state`: сколько слов нужно добавить в карточки, сколько карточек нужно подтвердить или сколько карточек уже в словаре.
- Таб `Тексты` показывает все завершенные тексты пользователя, включая несколько текстов за один день,
  если пользователь нажимал `Завершить текст` для каждого из них.
- Тексты, завершенные в один день, имеют одинаковый `completed_date` и отличаются временем `completed_at`.
- Таб `Словарь` показывает состояние словаря, карточки на подтверждение и подтвержденные карточки слов.

## 3) DB model
История прочитанных текстов хранится в таблице:
- `public.user_completed_reading_texts`

Ключевые поля:
- `user_id`
- `completed_date`
- `completed_at`
- `title`
- `body`
- `level`
- `estimated_minutes`
- `provider`
- `model`
- `fallback_used`
- `created_at`

Миграция создания таблицы:
- `supabase/migrations/20260427181000_create_user_completed_reading_texts.sql`

Для выдачи истории используется индекс:
- `idx_user_completed_reading_texts_user_completed`

RLS включен, frontend policies не добавлены. Доступ идет через Edge Functions с
`SUPABASE_SERVICE_ROLE_KEY`.

## 4) Completion transaction
Транзакционное завершение чтения выполняет RPC:
- `public.complete_daily_reading_text(...)`

RPC:
- берет advisory lock по пользователю и дате
- читает active text даты завершения с `for update`
- пишет дневной completion-marker для прогресса/streak
- сохраняет отдельный snapshot текста в `user_completed_reading_texts`
- удаляет active text даты завершения из `user_active_reading_texts`
- заполняет `users.first_text_completed_at` для онбординга

Миграции актуальной версии RPC:
- `supabase/migrations/20260427181100_complete_daily_reading_text_history.sql`
- `supabase/migrations/20260701120000_scope_active_reading_text_by_date.sql`

## 5) Edge Function
Историю отдает Edge Function:
- `supabase/functions/get-reading-history/index.ts`

Функция:
- принимает `initData`, `limit`, `cursor`
- валидирует Telegram `initData`
- находит пользователя по `telegram_user_id`
- читает только тексты текущего пользователя
- сортирует по `completed_at desc, id desc`
- возвращает `{ items, nextCursor }`

Пагинация cursor-based:
- frontend запрашивает первые `10` записей
- сервер выбирает `limit + 1`
- если есть следующая страница, возвращает cursor последней видимой записи
- кнопка `Показать еще` передает cursor в следующий запрос

## 6) Frontend
Типы:
- `src/types/materials.ts`

Сервис:
- `src/services/materialsService.ts`
- `src/services/vocabularyService.ts`

Экран:
- `src/screens/MaterialsScreen.tsx`

Поведение UI:
- табы находятся вверху экрана и показывают счетчики `Текстов: N` / `Слов: N`
- первым и активным по умолчанию отображается таб `Словарь`
- карточка текста показывает дату и время завершения, заголовок, preview текста, уровень, модель и время чтения
- полный текст раскрывается кнопкой `Показать полностью`
- повторное нажатие на кнопку `Свернуть` возвращает preview
- кнопка `Показать еще` догружает следующую страницу истории
- таб `Словарь` использует summary-карточку состояния с двумя compact status cards `Добавить` / `Подтвердить`; активные значения подсвечиваются warm-состоянием, нулевые значения показываются как blue ready-state `Все готовы` / `Подтверждено` с иконками `Layers` / `CircleCheck`; pending-слова показываются через fixed-height action `Готовить`, compact info panel, compact rows для слов и раскрываемые карточки с деталями, примерами и действиями
- встроенные ошибки материалов и словаря отображаются через `InlineStatusCard`

## 7) Current limitations
- У истории пока нет отдельного полноэкранного detail-view.
- Telegram `initData` validation продублирована в Edge Functions.
