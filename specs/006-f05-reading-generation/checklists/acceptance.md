# Приёмка F05

**Статус:** ручные сценарии не выполнены. Владелец отмечает результат после проверки.

- [ ] M-1. Валидная генерация и одна попытка.
  - Покрывает: AC-1, AC-2, AC-3.
  - Среда: локальный Telegram dev-бот, версия ветки после F05, Supabase local.
  - Предусловия: пользователь с завершёнными настройками, доступной попыткой и работающим тестовым OpenRouter; реальные токены не передавать агенту.
  - Шаг 1: открыть экран Текст и записать видимое число оставшихся попыток.
    - Ожидаемый результат: текущее состояние и счётчик отображаются.
  - Шаг 2: нажать генерацию один раз и дождаться результата.
    - Ожидаемый результат: новый текст открывается, загрузка завершается, счётчик уменьшается ровно на одну попытку.
  - Шаг 3: закрыть и заново открыть экран Текст.
    - Ожидаемый результат: тот же активный текст виден; новая попытка не списана.
- [ ] M-2. Безопасное сообщение при естественной ошибке AI.
  - Покрывает: AC-4, AC-6.
  - Среда: тот же dev-бот.
  - Предусловия: ошибка возникла естественно; специально портить ключ/production данные не нужно.
  - Шаг 1: прочитать сообщение об ошибке.
    - Ожидаемый результат: нет prompt, raw provider response, токена и секретов; результат не выдан за успешный текст.
  - Если ошибка не возникла, сценарий остаётся NotRun; отказ и безопасность дополнительно покрыты подставными тестами.
