## Решение и основания

Vitest запускает отдельные быстрые unit/component тесты на jsdom с React Testing Library; существующие `tsx --test tests/*.test.ts` остаются самостоятельным контуром. `pnpm test` объединяет оба, не удаляя прежние тесты. ESLint flat config проверяет TypeScript/React и hooks, Prettier проверяет целевой формат новых/затронутых файлов, Stylelint — CSS с Tailwind v4. CI использует pnpm lockfile и запускает проверки без БД.

CSS находится в `src/index.css` и использует Tailwind v4. F01 не меняет frontend/Edge/Postgres contracts. Согласованный набор прямых dev-зависимостей перечислен в обзоре; Playwright и Deno относятся к F02.
