# Приёмка F08

**Тип:** Acceptance. **Статус:** автоматические и ручные сценарии не выполнены.

- [x] A-1. Deno тесты save/delete: валидный запрос, повтор, лимит, смена текста, неверные параметры, prepared conflict и безопасная ошибка БД. Покрывает AC-1–6.
- [x] A-2. Read-only SQL tests проверяют ownership/lock/server-only RPC; не доказывают реальную гонку. Покрывает AC-1–4/6.
- [ ] M-1. Сохранение и удаление pending-слова.
  - Покрывает: AC-1/3/5.
  - Среда: локальный Telegram dev-бот на версии ветки после F08.
  - Предусловия: завершены настройки, есть активный текст и ещё не сохранённое слово.
  - Шаг 1: открыть «Текст», выбрать слово и нажать «Добавить».
    - Ожидаемый результат: слово отмечено сохранённым; после повторного входа отметка остаётся.
  - Шаг 2: выбрать то же слово до подготовки карточки и нажать «Удалить».
    - Ожидаемый результат: отметка исчезает, слово снова доступно для добавления; другие слова не меняются.
- [ ] M-2. Готовая карточка не удаляется действием из текста.
  - Покрывает: AC-4.
  - Среда: тот же dev-бот после подготовки карточки по F09.
  - Предусловия: активный текст содержит слово с готовой карточкой.
  - Шаг 1: выбрать готовое слово в тексте.
    - Ожидаемый результат: действие удаления pending-слова недоступно; карточка остаётся в словаре.

Ручные отметки ставит владелец после выполнения. Если локальный DB concurrency test не запускался владельцем, его результат остаётся NotRun.
